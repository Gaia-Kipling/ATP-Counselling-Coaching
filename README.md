# ATP Counselling & Coaching Website

A modern, responsive website for **ATP Counselling & Coaching**, designed to provide information about counselling and coaching services, allow potential clients to make enquiries, and present the practice in a professional and accessible way.

## Features

- Responsive design for desktop, tablet and mobile
- Modern, accessible user interface
- Counselling and coaching service information
- Contact and enquiry form
- Privacy Policy
- Terms & Conditions
- Custom 404 page
- Thank You confirmation page
- WhatsApp integration
- SEO-friendly structure

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Bootstrap 5.3
- Bootstrap Icons
- Font Awesome
- Google Fonts

## Installation

1. Clone the repository.

```bash
git clone https://github.com/Gaia-Kipling/ATP-Counselling-Coaching.git
```

2. Open the project folder.

3. Launch `index.html` in your preferred web browser.

No build tools or additional dependencies are required.

## Browser Support

The website is compatible with current versions of:

- Google Chrome
- Microsoft Edge
- Mozilla Firefox
- Safari

## Accessibility

The website has been developed with accessibility in mind and includes:

- Semantic HTML
- Keyboard-friendly navigation
- Skip-to-content link
- Appropriate heading hierarchy
- Descriptive alternative text for images
- Responsive layouts
